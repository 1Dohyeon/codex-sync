# 논문 리딩 작업 규칙

[`rules/workflow.md`](../../rules/workflow.md)의 5단계 위에서 진행되는, 단일 문서 정독 작업 고유의 규칙이다.

## 시작

- 정리 결과를 어디에 남길지 먼저 정한다. 임의로 정하지 말고 사용자에게 묻는다. 대화로만 낼 수도 있다.

## 읽기

- 문서 전체를 Read한다. 초록·서론만 보고 요약하지 않는다. PDF면 pages로 나눠 전부 읽는다.
- 저자 본인의 주장과, 저자가 인용한 선행 연구를 구분한다.

## 산출물 형식 (기본)

- **문제의식**: 무엇을 풀려는가
- **방법**: 어떻게 접근했는가
- **핵심 결과**: 무엇을 보였는가 (수치는 원문 그대로 옮긴다)
- **한계·전제**: 저자가 밝힌 것과 읽으며 걸린 것을 나눠 적는다
- **쓸 지점**: 이 문서가 지금 하는 일에 어디에 쓰이는가

주장별 근거 강도까지 보는 비판적 검토는 사용자가 요청할 때만 덧붙인다.

## 하지 말 것

- 안 읽은 절을 읽은 것처럼 요약하지 않는다.
- 원문에 없는 수치·결론을 만들지 않는다.
- 저자의 주장과 내 판단을 섞지 않는다.
